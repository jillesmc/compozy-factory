# ADR-001: Factory agents live in a separate repo and are installed by copy

## Status

Accepted

## Date

2026-11-17

## Context

The factory agents must be defined once at user level (`$COMPOZY_HOME/agents`) and attached to any
project. `$COMPOZY_HOME/agents` is not versioned. CompozyOS opens each agent directory with `O_NOFOLLOW`
(`internal/config/agent_discovery.go`), so symlinked agent directories are skipped. Extension-packaged
agents cannot run heartbeat source scripts and their HEARTBEAT.md is write-protected; the dispatcher and
auditor depend on scripts. Operator decision Q20 = b.

## Decision

A private repo `compozy-factory` is the source of truth. `bin/install` copies `agents/factory-*` into
`$COMPOZY_HOME/agents/` and `tools/` into `$COMPOZY_HOME/factory/tools/`, idempotently, touching nothing
else; `--prune` removes stale `factory-*` agents. Updates are `git pull && bin/install`.

## Alternatives Considered

### Alternative 1: Version `$COMPOZY_HOME/agents` itself

- **Description**: make the directory a git repo.
- **Pros**: no install step.
- **Cons**: mixes the factory with unrelated user agents (`general-*`).
- **Why rejected**: operator chose isolation (Q20 = b).

### Alternative 2: Symlink from the repo

- **Description**: link each agent directory.
- **Pros**: no copy.
- **Cons**: discovery skips symlinked directories.
- **Why rejected**: does not work.

### Alternative 3: Extension package

- **Description**: ship agents in an extension like `spec-cycle`.
- **Pros**: native install/update.
- **Cons**: extension source scripts never execute; HEARTBEAT.md write-protected.
- **Why rejected**: breaks dispatcher and auditor.

## Consequences

### Positive

- One versioned definition per agent; projects only hold `factory.toml`.

### Negative

- Forgetting `bin/install` after `git pull` leaves stale definitions.
- Source hash changes require re-approval after each install.

### Risks

- Install writing outside its paths. Mitigation: Safety Invariant 1, UT-005/UT-007.

## Implementation Notes

Prompts call shared tools with the absolute path `~/.compozy/factory/tools/<tool>` (expanded by the agent
shell). Source scripts stay inside each agent's `sources/` (they run from the approved private copy).
